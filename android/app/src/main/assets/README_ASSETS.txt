ASSETS FOLDER — FedFlower Android App
=======================================

This folder must contain TWO files before building the app:

1. flower_model.tflite  ← DOWNLOAD FROM COLAB AFTER RUNNING Phase4_Model_Conversion.py
   - The trained and quantized TFLite model
   - Size: 15-25 MB
   - How to get it: Run Phase4_Model_Conversion.py in Colab, then download via
     Files panel (📁 icon) → right-click flower_model.tflite → Download

2. flower_names.txt  ← ALREADY INCLUDED (generated by scripts/generate_flower_names.py)
   - 102 flower species names, one per line
   - Matches Oxford 102 Flowers label ordering (0-indexed)

WITHOUT flower_model.tflite, the app will crash on launch with a FileNotFoundException.
